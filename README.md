🌿 PlantCare AI

AI-Powered Leaf Health Classification & Robotic Monitoring Prototype

PlantCare AI is an intelligent plant monitoring prototype that combines machine learning and a robotic monitoring simulation to explore plant health monitoring.

🚀 Features

- AI Leaf Classification: Classifies uploaded leaf images into five trained categories.
- Disease Category Prediction: Identifies the closest matching category from the trained model.
- Prediction Scores: Displays category-wise confidence scores.
- Downloadable Reports: Generates a text report of the analysis.
- Robotic Monitoring Simulation: Demonstrates health, moisture and temperature indicators.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- Teachable Machine

⚙️ How It Works

1. Upload a leaf image.
2. The trained machine-learning model analyses the image.
3. PlantCare AI displays the predicted category and scores.
4. Download the analysis report.
5. Explore the robotic monitoring simulation.

⚠️ Project Limitations

This is an experimental educational prototype. Predictions are limited to the five categories used during training and are not confirmed agricultural diagnoses. Robotic monitoring is currently simulated; no physical sensors or robot hardware are connected.

🔮 Future Improvements

- Expand the training dataset.
- Improve model performance through testing.
- Explore real-time sensor integration.
- Develop physical robotic monitoring hardware.
